== Description ==

**UltraAddons for Elementor** is a feature-rich addon library for the Elementor Page Builder. It provides unique widgets, ready-made templates, and powerful tools to build complete websites easily using drag & drop — no coding required.

Create stunning pages in just a few clicks. UltraAddons works with any WordPress theme and plugin, offering advanced customization, flexible display conditions, and useful extensions.

### ⭐ Features
- 85+ Full Page Templates  
- 500+ Ready-to-use Blocks  
- Add Custom Fonts (Free)  
- Logical Widget Conditions (Show/Hide widgets by condition)  
- Custom Header for any page or entire site  
- Custom Topbar for announcements or offers  
- Custom Footer for any page or entire site  
- Display Elementor Page / Section / Template anywhere using shortcode (example: `[UltraAddons_Template id='123']`)  
- Many ready widgets  
- Woo Product Table with design, typography and styling controls  
- Wrapper Link for section/column/widget  
- Hover animation for any section/column/widget  
- Advanced Heading with color & typography controls  
- Advanced Button with color & typography controls  
- Advanced Slider with dynamic content and pre-built templates

### Header & Footer Builder
To replace or add to your theme's default header/footer using Elementor templates:

**Step 1:** Create an Elementor template: `Dashboard → Elementor Template → Add New` (create as Page template).  
**Step 2:** Go to `Dashboard → UltraAddons → Header Footer` and choose your template for header/footer.

### Shortcode: `[UltraAddons_Template id='template_id']`
Use this shortcode to display any Elementor page/section/template anywhere (widgets, posts, Gutenberg blocks). Example: `[UltraAddons_Template id='123']` — here 123 is the POST_ID of the Elementor template.
